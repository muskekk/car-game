## 3D Car Game

Create an **HTML-based 3D car game** with a fully English interface. The game should be optimized for both **PC and mobile devices** with a responsive design and controls.

### Settings

Players should be able to access a **Settings** menu where they can:

* Customize PC keyboard shortcuts and controls.
* Adjust the game volume and sound settings.
* Configure controls for PC and mobile devices.
* Change other gameplay preferences when available.

### Play Game Menu

When the player clicks **Play Game**, a game setup menu should appear before the game starts.

On the **left side of the menu**, a fully interactive **3D car model** should be displayed.

The player can click on the car to customize its appearance, including changing its **body color**.

The menu should also include:

* **Manual / Automatic** transmission selection.
* **Theme selection** using the Left and Right Arrow keys.
* **Game Mode selection** using the Left and Right Arrow keys.

### Themes

The game should include the following visual themes:

* **Tokyo Night**
* **Dracula**
* **Monokai**
* **Molokai**
* **Henna**
* **Oceanic**

Players can switch between themes using the **Left and Right Arrow keys**. The selected theme should change the overall appearance of the menus and game interface.

### Game Modes

Game modes should also be selectable using the **Left and Right Arrow keys**.

#### Speed

A **time-trial racing mode**. The player must complete the track or reach the target within the given time limit.

#### Parking

The player first drives around the map for a while. Afterward, a designated parking area appears, and the player must **park the car correctly**.

#### Drift

A dedicated **Drift Meter** appears on the right side of the screen. The player must perform successful drifts to fill the meter. After completing the required number of laps or reaching the objective, the game ends and the player's performance is evaluated.

#### Highway

A straightforward highway-driving mode. The player drives along a long, mostly straight road and completes the game after reaching the required distance.

#### Free Mode

A relaxed and open-ended driving mode where the player can freely explore the map and drive wherever they want. However, collisions are still dangerous, and crashing into walls, barriers, or other vehicles will end the game.

### In-Game Environment

The gameplay environment should have a **dark nighttime atmosphere**.

The main roads should generally consist of **three lanes**, with the road layout changing depending on the selected game mode.

The map can contain:

* Three-lane roads
* Intersections
* Turning points
* Curved roads
* Walls and barriers
* Other vehicles
* Different road sections
* Various driving areas

The player must avoid collisions.

**If the player crashes into a wall or another vehicle, the game immediately ends.**

Depending on the selected game mode, the road layout, number of turns, traffic density, objectives, and driving conditions should change to provide a different gameplay experience.

### Controls

#### PC

* Keyboard-based vehicle controls.
* Fully customizable keyboard shortcuts.
* Left and Right Arrow keys for navigating menus.
* Customizable controls through the Settings menu.

#### Mobile

* Touchscreen controls.
* On-screen steering and driving buttons.
* A responsive interface designed specifically for mobile screens.

### Overall Goal

The goal is to create a modern-looking **3D HTML car game** with a dark nighttime atmosphere, interactive 3D vehicles, car color customization, manual and automatic transmission options, multiple visual themes, several unique game modes, customizable controls, and full support for both **PC and mobile devices**.
